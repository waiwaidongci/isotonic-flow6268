# 舫纹滤层压差响应簿

舫纹过滤材料组的 12 位试验员把独立滤片的流速与压差整理成单调响应研究，并为下一档独立试验留下可审阅的说明。上游来自 `fw-pressure-1-202611.csv` 等试验文件，下游由负责人批准后交复验观察员下载 CSV。原来在表格里手工连均值的三个问题是：局部逆序没有解释、平滑曲线超出观测域、训练误差被当成新档预测误差。

本项目用按独立读数条数加权的非降 PAVA，配合观测域线性插值、目标压差逆集合和留一整档 LODO。三项研究各 12 档、每档 8 片，共 288 条固定 seed 合成观测：局部逆序、平台响应、恒定对照。数据不含真实滤片商业性能或身份。

同一台压差仪可以服务多项研究；校准一旦补发，旧读数的解释就变了。因此每条原始读数额外记录仪器与测量时刻，拟合前按测量时刻所在**有效时段的倍率与零点**逐片校正压差，原始值原样保留。校准可以分段更正；时段重叠或留下缺口时，系统逐片指出受影响滤片，而不是悄悄挑一段。更正后只自动重算受影响研究；跨段读数在同一项研究里各用对应校准。并发更正或旧任务晚到时，整项研究的当前结果只采用与当前校准文档同一版本的结果，旧任务标 `superseded` 且不覆盖较新结果；失败任务可重试恢复。曲线页可追查每片采用的时段与失效原因。**未绑定仪器的旧研究沿用原分析**，只使用原始压差，不因校准时段的措辞而改变。

## 一天的试验剧本

1. 09:00，压差试验员宋桥登录“响应总览”，先区分训练误差与整档预测误差。
2. 到“滤片与档位”选择 `FW-28A 局部逆序滤片`，核对 `fw-pressure-1-202611.csv`。12 档流速 10–120 mL/min，每档8片，滤片编号如 `FW1-F04-P01`。
3. 核对独立滤片来源；同片重复测量不能换个编号冒充独立重复。可以导入带 levels/readings 的 JSON；同流速的多个命名档会合并。
4. 在“拟合配置”预先固定物理非降方向，目标压差6.5 kPa，查询流速 `5,35,45,80,125`。送入 PAVA 与 LODO 队列，不从数据搜索方向。
5. “曲线与留档”显示 A 研究的40/50 mL/min两档合并，权重16、拟合压差6.52278638 kPa；共11个算法块。A 研究前六档测量于 2026-10-20、后六档于 2026-11-02，跨 v1 的两个校准时段；40/50 两档都在同一旧时段。校正后训练读数 MSE0.06408168150（未校正对照0.20368069642），LODO MSE0.69452844804，12次真实重拟合。
6. 目标6.5 kPa的域内线性逆解约39.84104945 mL/min；查询5和125都明确标端点夹持。夹持不构成外推能力。平台目标会返回整个区间，范围外无解。
7. 读每一折的留出流速、训练读数数、逐滤片残差；端点两折16片也计入总MSE，域内读数MSE另列0.61282188513。
8. 到“独立复验”提出45 mL/min的新档取样，写明另取独立滤片、核对原始压差。说明冻结整份结果，不把拟合响应当下一档保证。
9. 负责人许澜批准或退回，观察员叶衡下载批准快照 CSV；过程留痕记录导入、修订、队列、审批与导出。重复审批409，修改底稿不能改写既有批准快照。
10. 若压差仪事后补发校准：到“校准更正”查看当前 v1（2026-11-01 前倍率1.0/零点0，其后1.04/0.05）。A 研究前六档在 10-20 测量、后六档在 11-02 测量，因此同一项研究跨两个时段。发布 v2 时给出分段（例如把 11-01 之后改为1.10/0.10），系统列出受影响滤片并只排队受影响研究。若新分段相互重叠或在 10-20→11-02 之间留下缺口，逐片标出 `overlap`/`not_covered`，该项研究暂停重算而不冒充当前结果。修正后可重试。
11. “曲线与留档”顶部显示当前结果采用的校准版本与参与时段数，节点表并列原始均值与校正均值；训练 MSE 同时给出未校正对照。旧版校准的运行保留为历史，不覆盖较新结果；失败运行可点“重试 ↻”，无需重建底稿。

## 校准口径

仪器 `Instrument` 持有版本化校准文档；每个版本由互不重叠的 `CalibrationSegment` 有效时段组成，每段给倍率 `m` 与零点 `b`，校正后压差 `p' = m·p + b`。时段按 `[effective_from, effective_to)` 判归属：`effective_to` 为空表示至今。研究可选绑定一台仪器；绑定后每条读数必须有带时区的测量时刻，且该时刻恰有一个生效时段，否则拒绝绑定（422）并逐片列出原因。测量时刻要么整项研究齐全、要么全部留空：部分标记无法归属，直接拒绝。

发布新版本时旧版本转为 `superseded`，历史保留。系统对绑定该仪器的每项研究逐片比较新旧时段：时段重叠或缺口、时刻无覆盖、校正后为负或非有限，都进入 `invalidated`，该研究当前结果停用且不自动重算；数值确有变化的读数进入 `changed`，只重算这些研究。重叠按相邻时段的交集报告，缺口按相邻时段之间的开区间报告，并映射到实际受影响的滤片编号。

每个运行在排队时冻结 `calibration_snapshot`（仪器、版本、全部时段与文档指纹）。worker 计算前再次校验：若当前生效校准已不同步，本任务只代表旧版，标 `superseded` 并触发重算，**不发布**；若同研究已有更新编号的当前结果，同样不覆盖。整项研究的“当前结果”只允许与当前校准文档指纹一致的结果，`is_current` 唯一。失败运行保留诊断（`analysis_error` 或 `calibration_invalid` 及逐片失效），可由“重试”以同一配置重新排队，成功后恢复当前结果。未绑定仪器的研究没有快照，运行按原分析只使用原始压差，`is_current` 逻辑仍保证同一研究只有一个当前结果。

## 数学口径

输入有命名档 DoseLevel 与每片 PressureReading。同一研究中的 specimen_ref 必须唯一；绑定仪器的研究先按测量时刻逐片校正压差（原始值仍保存），再在相同流速 x 上合并所有命名档，计算校正后读数均值 μⱼ 和条数 nⱼ。跨时段读数各用其对应校准参与同一均值；每档节点同时保留原始均值与逐片采用的时段，供追查。PAVA 解 `min Σ nⱼ(μⱼ−θⱼ)²`，约束 `θ₁≤…≤θₖ`。权重是独立滤片数，不是任意可靠性评分。

按流速排序，用相邻块栈逐一合并违反非降的块，以加权均值更新。相等而未违反约束的相邻块可保留多个算法块；平台逆集合仍覆盖所有相等拟合节点，块数不代表物理变化次数。保存每块索引、权重和拟合值、完整节点均值/计数。数学操作使用 NumPy longdouble 以减少加权累计舍入，结果以 JSON 浮点保存。

观测域 `[min(x),max(x)]` 内连接相邻拟合节点，得到连续非降线性曲线。域外查询只返回最近端点值，并标记 left/right clamp，不称外推。逆集合指观测域内满足 `f(x)=目标压差` 的全部流速：严格上升处为一点，平台为闭区间，超出拟合压差范围无解；恒定曲线合法，目标等于常量时返回整个观测域。比较基于保存的浮点节点精确相等，没有人为扩成置信带。

LODO 每次去掉一个独特流速的全部原始读数（包括所有同x命名档），在剩余档位重新执行 PAVA，然后插值或端点夹持预测留出档。保存每折训练流速/读数数/拟合节点/块、留出预测、每片原始残差与平方误差。`总MSE=Σ所有留出原始读数误差² / 原始读数总数`，不是不等档数时对各折MSE简单平均；MSE单位为kPa²。端点夹持折计入总值，并另列夹持数和域内MSE。

手算例 x=[1,2,3]，均值=[3,1,2]，独立数=[1,3,1]，PAVA=[1.5,1.5,2]；目标1.5的逆集合[1,2]，目标1.75逆解2.5，LODO各折预测[1,2.5,1.5]，原始读数总MSE2.2。简单折均值约2.16667，与正确总MSE不同。浏览器实际导入也验证此例。

方向由试验前物理假设声明，不按测试误差选择。滤片独立、与新档采样机制可比是LODO解释的前提；同片相关重复会破坏独立读数权重解释。LODO与逆集合不提供置信区间、因果归因、材质合格或外推承诺。平滑和平台是约束模型的确定性结果，仍需独立复验。

## 校验、审阅和工程结构

每研究2–30命名档、至少2个不同流速，每档1–30读数，总计≤600；流速有限且0–1000，压差有限且0–1,000,000，查询≤30项。校准倍率须有限正数、零点有限，时段结束须晚于开始；跨研究同日可并列多段，但同一时刻只允许一个生效时段。相同x合法并聚合；全同x、重复滤片编号、空档、非有限、负压差与错误方向拒绝。统一422错误不回显非法NaN输入，避免默认错误对象再次JSON编码失败。worker独立重验；校准时段无法唯一归属时整项研究不发布结果，失败任务保留诊断并可重试。

有职责的 Python/TS/TSX/CSS 文件（不含空包、依赖和dist）覆盖八实体 Instrument → CalibrationVersion → CalibrationSegment 与 FlowStudy → DoseLevel → PressureReading → MonotoneRun → ValidationNote，贯穿 ORM/schema/service/routes、前端API/store 和七页：响应总览、滤片与档位、拟合配置、曲线与留档、独立复验、校准更正、过程留痕。

前端 `src/{api,stores,types,components/common,hooks,pages,router,utils,constants}`；后端 `src/{routes,controllers,services,models,schemas,middlewares,utils,constants,config}`，另 scripts/seed_demo.py 与 migrations/。共享组件 ResponsePlot、FitDigest、InverseSet、RunList 在多页复用，LodoTable与common组件提供一致解释；useTask/useRoute和format工具处理状态与格式。

Role、RunStatus、NoteStatus 后端位于 `backend/src/constants/enums.py`，前端对应 `frontend/src/constants/enums.ts`。JWT授权、审计、RequestID/Error/Redis写限流三个中间件形成横切链路。写配额按令牌摘要（无令牌时IP）与分钟计数，超限429含Retry-After，健康读取不计；限流存储不可用返回503。批准以数据库行锁保证 draft 只能审一次，冻结 result_snapshot 供CSV导出。
